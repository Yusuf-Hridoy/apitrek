What is API Sentinel?

AI-powered API testing. Enter an endpoint and it generates positive, negative, and edge test cases plus assertions — which you can execute live, export, or scan for security issues.

Functional Testing

  • Enter an API Endpoint and pick an HTTP method.
  • Tick Auto-fetch sample response to call the API and use its real response, or expand Add headers, body & sample response to paste one.
  • Click Generate Test Cases. Run tests individually or use Run All Tests against the live API.
  • Export a Pytest script, a Postman collection, or a CI/CD pipeline (GitHub / GitLab / Azure).

Security Scanning

Switch to Security Scanning to probe the endpoint against the OWASP API Top 10. Only scan APIs you own or are authorized to test. Results include a risk score and an exportable Markdown/HTML report.

Import from OpenAPI

Click Import from OpenAPI to paste a 3.0/3.1 spec (JSON or YAML), pick an endpoint to load it into the form, and validate live responses against the documented schema (contract testing).

History

Every generation and run is saved. Open History to reload, rerun, or delete past sessions.
